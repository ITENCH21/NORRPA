# Концепт редизайна сайта norppa.ru

Многостраничный статический сайт без сборщиков и зависимостей. Шрифт Onest — из Google Fonts. Фото — по прямым ссылкам с norppa.ru (static.tildacdn.com) и shop.norppa.ru. Погода — из бесплатного API open-meteo.com.

## Страницы
| Файл | Раздел |
|---|---|
| `index.html` | Главная: живая погода и подбор моделей, лукбук, «Для всей семьи», куртка в разрезе, нерпа, магазины |
| `collection.html` | Коллекция осень–зима 2026: Кольский полуостров, палитра, 8 моделей с ценами, лукбук |
| `technologies.html` | Технологии и уход: мембрана, утеплители, полиуретан, софтшелл, без подкладки, молнии, графен, Silver Plus, E.M.F., уход |
| `stories.html` | Истории: Фонд друзей балтийской нерпы, интервью с друзьями бренда, весна–лето 2026 |
| `about.html` | О бренде: философия, история названия, путь бренда |
| `stores.html` | 9 фирменных магазинов, интернет-магазин, бонусная и подарочная карты |
| `business.html` | Корпоративные заказы с формой заявки и вход для оптовых покупателей |
| `bonus.html` | Бонусная программа и подарочная карта |
| `catalog.html` | Каталог: 202 модели, разделы, фильтр по типу изделия, «только со скидкой», сортировка |
| `product.html?id=…` | Карточка товара: галерея по цветам, размеры с наличием, характеристики, состав, доставка, похожие модели |
| `cart.html` | Корзина и оформление заказа (в концепте заказ уходит письмом на office@norppa.ru) |
| `story-*.html` | Полные интервью: Ирина Турчинская, Елизавета Белоусова, Иван Проскурин |
| `privacy.html`, `cookie.html` | Политика обработки персональных данных и политика cookie |

Общие файлы: `assets/style.css` (все стили), `assets/site.js` (шапка, меню, cookie, панель «Что изменено», магазины, формы), `assets/shop.js` (каталог, карточка, корзина) и `assets/catalog-data.js` (данные 202 моделей на 17.11.2026).

## Как показать
- **GitHub Pages:** https://itench21.github.io/NORRPA/
- **Локально:** откройте `index.html` двойным кликом.

## Как править
Шапка, подвал и панель «Что изменено» общие для всех страниц. Они собираются скриптом `redesign-src/build.py` из папки «NORPPA аудит» на рабочем столе. Тексты страниц лежат в `redesign-src/pages/`. После правки запустите:

```bash
python3 build.py
```

## Важно
- Ни одна ссылка не ведёт на norppa.ru или shop.norppa.ru: каталог, интервью и документы — внутри концепта. Фото по-прежнему загружаются с серверов NORPPA.
- Корзина хранится в браузере покупателя; оформление отправляет письмо. В рабочей версии сюда подключаются оплата и обмен с 1С-Битрикс.
- Цены зафиксированы на 17.11.2026.
- Стоит `noindex`: это концепт, поисковики его не индексируют.
