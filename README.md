# Концепт редизайна главной norppa.ru

Одностраничный концепт в одном файле `index.html`, без сборки. Шрифт Onest подключается из Google Fonts. Фото берутся по прямым ссылкам: кампания осень–зима 2026 — с static.tildacdn.com (сайт norppa.ru), товары — с shop.norppa.ru. Погода — из бесплатного API open-meteo.com, ключ не нужен.

## Что на странице
- **Первый экран** — диптих из кадров кампании, проявление заголовка, параллакс при прокрутке.
- **«Что надеть сегодня»** — живая погода в Петербурге, Москве или Самаре. Анимация дождя, ветра или снега на фоне и 4 модели с ценами под эту погоду. Погоду можно выбрать и вручную.
- **Лукбук** — горизонтальная лента кадров, листается и перетаскивается мышью.
- **«Для всей семьи»** — крупный список категорий; при наведении за курсором появляется фото.
- **«Куртка в разрезе»** — слои ткань → мембрана → утеплитель → подкладка расходятся при прокрутке.
- **Нерпа и фонд, 9 фирменных магазинов с вкладками по городам, входы «Компаниям» и «Магазинам», подвал с едиными контактами.**
- **Кнопка «Что изменено»** (справа внизу) — для презентации: список улучшений относительно текущего сайта.

Анимации отключаются, если в системе включено «уменьшение движения».

## Как показать
- **Локально:** откройте `index.html` двойным кликом. Погода подтянется, если есть интернет.
- **GitHub Pages:** загрузите `index.html` в репозиторий и включите **Settings → Pages → Deploy from a branch → main / (root)**. Можно положить обе страницы в один репозиторий — в папки `redesign/` и `site/`. Тогда адреса будут `…github.io/<репозиторий>/redesign/` и `…/site/`.

## Перед показом стоит знать
- Цены зафиксированы на 17.11.2026 и при показе могут отличаться от магазина.
- Стоит `noindex`: это концепт, поисковики его не индексируют.
- Если компания решит внедрять дизайн, сайт можно собрать на их текущей Tilda (Zero Block) или в Битриксе магазина. Блок с погодой переносится как отдельный скрипт.
